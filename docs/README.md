# Thiết kế và ghi chú tích hợp QuickMeets

- Figma: thêm liên kết bản thiết kế chung khi đã có.
- Repo Web: https://github.com/NhLinh2610-maker/Quick-Meet
- Trước khi triển khai phòng họp, thống nhất với nhóm Web/backend về mã phòng, token tham gia phòng tạm thời, các sự kiện thời gian thực và API cho file đính kèm.
- Chức năng dự kiến: phòng họp không cần đăng nhập (tối đa 10 người), gọi thoại/video, chia sẻ màn hình, chat trong phòng, tải file theo yêu cầu và lưu bộ nhớ đệm, dọn dẹp phòng khi mọi người đã rời đi.

Thư mục này dùng để ghi lại quy ước tích hợp với backend dùng chung; ứng dụng Android không triển khai hoặc vận hành backend riêng.
